Field reference
  • req — title, company, location, seniority_band, must_haves[]
  • weights — optional override, must total 100
  • candidates[].sources — {seekout, pin}; both true is the confidence signal
  • candidates[].pin_status — unreviewed · shortlisted · accepted · rejected · not_found
  • candidates[].band — on_target · stretch_senior · stretch_junior · adjacent · probe
  • candidates[].scores.<dim> — {rating: 0–5 or null, evidence}. Use null when there is no evidence; never guess a rating.
