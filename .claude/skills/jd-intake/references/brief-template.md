# Brief template

Post this in chat. The scorecard tables come from `scripts/score_candidates.py` — paste
its output in rather than re-typing numbers, so the brief and the committed artefact agree.

```markdown
# Intake brief — [Role] @ [Company]

## Role as read
- **Real title / level:** ... (note it if the posting's title is inflated)
- **Must-haves:** the 3–6 that survived the wish-list cut
- **Nice-to-haves / deal-breakers:** ...
- **Seniority band:** years + scope of ownership
- **Location / remote:** ...

## Open questions for the client
Up to two genuine ambiguities. Skip the section if the JD is clear — manufactured
uncertainty wastes the client's attention.

## Where this talent sits
8–15 named companies grouped by why they're a pool, not an undifferentiated list.
Say what each cluster shares — comp band, stage, pace, the specific skill.

## How the slate was built
- **SeekOut:** boolean, filters, pool size, and the shareable search link.
- **Pin:** ranked pool from the same JD.
- **Cross-reference:** N in both, N SeekOut-only, N Pin-only, N pipeline conflicts removed.
- **Query repair:** if Pin-only results forced a boolean widen, say what changed and why.
  This is the part that shows the search is being run honestly.
- **Rubric:** default weights, or the override and the reason for it.

## Scorecard
[paste scorer output: ranked slate, held-out profiles, rubric, per-candidate reasoning]

## What this slate tests
Two or three sentences on the spread. Which profiles probe the seniority band, which
probe the domain must-haves, and what a client reaction to each would tell us.

Be explicit that fit and confidence are different axes — a well-evidenced 78 is a
stronger read than a thinly-evidenced 92, and the client should react to the profile,
not to the number.

## Next
- Save this calibration to the req's memory
- Shortlist any of these (no outreach)
- Save the SeekOut search to a workspace
- Start outreach — only on an explicit go
```

## Tone

Write like a recruiter briefing a client, not like a report generator. Say what you
found and what you're unsure about. Where the data was thin, say it was thin. Where two
engines disagreed, say so and say what you did about it — a client who can see the seams
trusts the slate more than one handed a clean surface with nothing behind it.
